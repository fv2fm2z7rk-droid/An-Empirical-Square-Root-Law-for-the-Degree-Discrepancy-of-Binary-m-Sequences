# Degree discrepancy profiles for binary m-sequences

Code and data accompanying the note
*An Empirical Square-Root Law for the Degree Discrepancy of Binary m-Sequences*.

Preprint: The PDF is also from the author, Joonas Pääkkönen, jpa@du.se., Joonas Pääkkönen, `jpa@du.se`.

| File | Role |
|---|---|
| `full_rho_profiles.json` | Degree-discrepancy profiles for \(k=2,\dots,28\) (source of Table 1 and Figure 1) |
| `full_rho_profiles_all.py` | Main driver: exact sliding windows for \(k\le 14\), Monte Carlo for \(k\ge 15\) |
| `full_rho_profiles_k28.py` | Dedicated \(k=28\) runner (short windows first) |
| `full_rho_profiles_k28_down.py` | Same \(k=28\) runner, long windows first |
| `plot_argmax_horizons.py` | From those profiles: first and top-3 \(r^\ast/M\), plus Figure 2 |
| `argmax_horizons.json` | Table of recorded maximizers (regenerated by the plot script) |
| `make_figures.py` | Regenerates the two manuscript figures |
| `figures/` | `fig_normalized_peaks` and `fig_argmax_horizons` (pdf/png) |

Rebuild (or extend) the JSON with:

```bash
python3 full_rho_profiles_all.py
```

Plot where each profile maximum sits (no new scans):

```bash
python3 plot_argmax_horizons.py
python3 make_figures.py
```

The square-root note compares \(\max_r\Delta(r)\) to \(\sqrt{N}\). A Brownian-bridge heuristic for that *scale* has variance \(\rho(1-\rho)\) and therefore a typical peak near mid-path, \(\rho=r/M=1/2\). Complement symmetry \(\Delta(M-r)=\Delta(r)\) makes a recorded maximizer at \(\rho\) interchangeable with one at \(1-\rho\), so the folded location \(\min(\rho,1-\rho)\) is the quantity that tests “near mid-path”. On the existing 28-point grids the first argmax does **not** hover around \(1/2\): the folded location is below \(1/4\) for several \(k\) (including \(k=16,28\)). Mid-horizon \(\Delta\) is still a large fraction of the peak, so the \(\sqrt{N}\) *scale* can survive even when the recorded horizon is off-centre.

The same range has two readings of the starting offset: a pairing fragment in serial-knockout scheduling, and a change to the plaintext on an LFSR orbit. The second is a reading of the statistic, not a cipher analysis.
